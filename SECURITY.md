# Security Policy & Vulnerability Disclosure

## Reporting a Security Vulnerability
If you discover a security vulnerability within the **Sentinel Intelligent API Security Platform**, please notify our Security Response Team at `security@sentinel-project.org` or open a confidential security advisory.

### Vulnerability Response SLA
- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Severity Assessment**: Within 48 hours.
- **Patch Release & Advisory**: Critical (7 days), High (14 days).

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: Yes |
| < 1.0 | :x: No |
